Keeper plugins for AI agents, with the guardrails left on.

A Claude Code and Cursor plugin marketplace and a local MCP server that drive the Keeper Commander and Secrets Manager CLIs. Secrets are redacted by default and risky actions need explicit confirmation.

Install View on GitHub

Four plugins

keeper-admin

Vault records, enterprise admin, PAM sessions, rotation, compliance reports.

keeper-msp

Managed companies, licenses and add-ons, MSP billing reports.

keeper-secrets

Secrets Manager: ksm exec, templates, CI/CD, Keeper notation.

keeper-setup

Install the CLIs and set up profiles for the first time.

Quick start

/plugin marketplace add patrickking67/keeper-security
/plugin install keeper-admin@Keeper-Security

For other agents, use the Skills CLI: npx skills add patrickking67/keeper-security.

Local MCP server

keeper-mcp is a stdio server with 26 tools. Each tool runs one Commander command as a captured subprocess and returns the output. It starts with no configuration and never prints to the MCP stream. It can be packaged as an MCPB bundle for Claude Desktop.

  • Record secret fields are scrubbed unless reveal_secrets is set.
  • Moving a user's vault requires confirm=true.
  • The generic command tool refuses shell, login, connect and logout.
  • Line breaks and NUL bytes are rejected in every command, so nothing can be smuggled into a batch.
  • The test suite runs offline and never contacts a Keeper tenant.
